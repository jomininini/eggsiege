# 金蛋争夺战：科学园前线 / Golden Egg Siege

以香港科学园临海园区为灵感的原创低多边形 3D 第一人称据点射击（Three.js + TypeScript + Vite）。单人对 AI，开局即玩，无需登录联网。界面支持 **简体中文 / English** 一键切换（标题页、设置与暂停菜单右上角）。

## 玩法
- 红方·赤焰 vs 蓝方·海鹰，争夺 A/B/C/D 四个建筑据点与中央「金蛋」（高锟会议中心）。
- 胜利：先到 1000 分；或占领金蛋并连续守住 120 秒；时间耗尽时积分领先方获胜。
- 餐厅 = 补给点（弹药、手雷 +2、导弹 +2）；科技公司 = 技能点；会所 = 回血点。
- 金蛋脚下是**金蛋湖**，经**水道**与大海相连（水道上有两座桥），快艇可直接驶入湖中登陆金蛋。
- 载具：道路轻型战车、码头登陆快艇、屋顶无人机坪（侦察标记、呼叫直升机 / 火箭炮）、停机坪直升机。

## 出海模式（标题页可选）
- **出海岛**（第 6 个据点 ISL）离岸约 100 米（为初版两倍），海域整体扩大至 1.5 倍；双方乘快艇或登陆艇抢滩夺岛。
- **飞鱼高速登陆艇**（每方码头尽头 1 艘）：载 5 名步兵；玩家驾驶时在码头停稳，附近友军自动登艇，靠岸按 E 后全体随你登陆；AI 也会组队乘登陆艇抢滩。艇毁时乘员落水受伤。
- **武装直升机**（每方部署区旁 1 架，可驾驶）：空格爬升 / C 下降、WASD 平移、鼠标转向、左键机炮、右键火箭弹；降落后按 E 离机；可降落在**出海岛停机坪**，己方占岛时在此修理并补满火箭。AI 武装直升机会定时出击夺岛 / 争金蛋并返航。
- **运输直升机**可降落出海岛：在停机坪按 E 后选择 6 号目标，直升机实际着陆让你下机，随后起飞提供火力支援。
- 占领后获得：**海盾防空炮** ×2（F 切换瞄准 / 锁定模式，打击直升机与无人机）、**潮汐远程火箭炮**（10 连齐射大范围轰炸科学园，地面红圈预警）、**巡逻艇**（经水道直达金蛋湖），以及出海岛重生点（阵亡后按 2）与**岛上弹药补给库**（快速补弹与导弹）。
- 所有武器都可攻击船只；岛上武器可被摧毁并自动修复。

## 单兵武器
- KT-9 脉冲步枪；**P-7 手枪**（无限备弹，但 12 发弹匣需换弹；步枪弹药耗尽时自动切换，并提示最近补给点方向与距离）；**飞鱼-2 便携导弹**（Q 循环或 1/2/3 选择）：可打击步兵、战车、船只、直升机、无人机与岛上武器；右键持续瞄准载具/飞行器锁定后发射即自动追踪。

## 选项
- 作战模式：标准 / 出海；每队人数 2–10；难度：新兵 / 老兵 / 精英 / 传奇。

## 操作
WASD 移动/驾驶 · 鼠标瞄准 · 左键射击 · 右键机瞄/锁定 · Q / 1·2·3 切换步枪/手枪/导弹 · R 换弹 · Shift 冲刺 · 空格跳跃 · C/Ctrl 蹲伏 · G 手雷 · E 交互 · F 防空炮模式 · B 无人机中呼叫火箭炮 · 1-6 直升机目标（6 = 降落出海岛）· 武装直升机中 空格/C 升降 · Tab 战况 · Esc/P 暂停

## 开发
- `pnpm dev`（PORT=3000 HOST=0.0.0.0）· `pnpm build` → `dist` · `pnpm test`
- `node scripts/smoke.mjs`：端到端冒烟测试（先 build；或设 `SMOKE_URL`），覆盖标准模式、英文界面、出海模式、防空炮、火箭炮、导弹锁定、出海岛重生、登陆艇载员、武装直升机起降射击与直升机降落出海岛。
- 参数在 `src/game/config.ts`；地图在 `src/game/map.ts`；双语文本用 `src/game/i18n.ts` 的 `L(中文, English)`。
